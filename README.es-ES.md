Una herramienta de visualización RGB de hardware y software moderna y altamente optimizada, diseñada y probada específicamente para portátiles Lenovo LOQ y Legion con teclados RGB de 4 zonas. Este kit de herramientas ofrece una interfaz gráfica elegante e inspirada en Fluent Design que te permite personalizar la iluminación del teclado de forma dinámica.

**Versión actual**: *v3*

## Características

### Modos de hardware

- Apagado
- Estático
- Pulsación
- Suave
- Onda

### Modos de software

- Onda suave
- Relámpago
- Fiesta
- Fuego realista
- Escáner (Cylon)
- Aurora Boreal
- Lluvia de meteoros
- Color de pantalla ambiental
- Visualizador de batería
- Aura reactiva al mouse
- Temporizador Pomodoro
- Visualizador de audio en vivo
- Modo de temperatura
- Escritura reactiva
## Compatibilidad con el hardware

**Probado y soportado oficialmente:**
- Lenovo Legion Series (modelos 2020-2024)
- Lenovo LOQ Series (modelos 2023-2024)
- Debe contar con un teclado RGB de 4 zonas.

> Nota: El uso de este software en hardware no compatible, como teclados RGB por tecla o dispositivos que no son Lenovo, puede provocar un comportamiento inesperado, la incapacidad de localizar el controlador o cierres inesperados.
